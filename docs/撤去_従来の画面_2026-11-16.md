## 変えていないもの (確かめたこと)

- **本番の動き**: 本番はずっとシンプルな画面だったので、見えるもの・読みに行くものは同じ。ホームの見回り (30 秒)・ヒーローの描き直し・運営タブの見回りは撤去の前と同じ条件。
- **通知の送り手**: 模擬タブの裏描きは消したが、運営タブの裏描き (`prerender: true`) が盤面を読むので、撃破・時間の通知の送り手になる端末は変わらない (ふるりの決定 11/13「止めない」)。
- **DB**: SQL は足していない・変えていない (59 のまま)。`seasons.metadata.member_input` と RPC の白リスト (51 / 59)・練習の偽サーバの写しは残る (アプリは読まない・書かない)。
- **練習モード**: 元から従来の画面を使っていない。通し確認 (スマホ・PC) は撤去の前と同じ手数で最後まで行く。
- **見た目**: メンバーに見える変更は、ホームの「次にやること」の文 2 か所 (「レーダーが完成」→「5 属性そろっています」など) だけ。更新履歴には載せていない。

## やり方 (次も同じ手順で)

`scripts/cleanup/README.md`。要点: 入口 (HTML と分岐) を手で消す → 到達できない関数を機械で消す (0 個になるまで) → 孤立した変数・CSS → 消した名前への参照が残っていないかの検算 →
テストは「消した機能を見ていた assert」を記録つきで外し、数え方が変わっただけの見張りは数字を直して戻す → 練習の通し確認と物差しの検査。
