## ① メンバー向け

```text
📣 **ユニオンレイドのやり方が変わります (PAD の「時間割」と「✓ 凸しました」)**

**🗓 前日まで — Discord に書く (PAD への入力はありません)**
1. 出られるブロックと凸数 (例:「朝 1・夜 2」)。出られない回は「今回は難しい」と一言
2. 模擬のスクショ (属性ごとに 1 つ。18 時以降に出る人はボス 5 だけ 2 編成)
3. 凸先の希望があれば (例:「夕方に 風圧PT の編成①」)

ブロックは 6 つ: 朝 5〜8時 / 午前 9〜12時 / 午後 13〜16時 / 夕方 17〜20時 / 夜 21〜翌0時 / 深夜 翌1〜4時

**⚔️ 当日**
1. 「🧱 あなたの凸が決まりました」の通知が来たら、PAD のホームの **📅 きょうの凸** (時間割) で自分の行を見る (ボス・PT・編成)。後のブロックであなたの凸が決まるたびに、また届きます
2. 時間割のすぐ上の「配信された凸プラン」の **✅ 確認しました** を押す
3. ブロックの時間内に凸したら、自分の行の **✓ 凸しました** を押す (数字は入れません。押し間違えたら「取り消す」)
4. 「🔄 あなたの凸が変わりました / 外れました」が来たら、時間割を見直してもう一度 ✅
5. 行けなくなったら Discord で一言

**🔔 はじめに 1 回だけ**: PAD で名乗って通知を ON (iPhone は先に「ホーム画面に追加」。Safari のタブのままだと通知が来ません)
```

## ② 運営チーム向け

```text

**🗓 前日まで**

   - 希望がある人は、ピースを選んでボスの行に置く (📌)
   - **🧮 残りを自動で組む** (手で置いた駒は動かない)
4. 見通せるなら 午前・午後…も続けて組む (残り HP を引き継ぐ。5 体撃破したブロックの次から Lv が上がる)

```
