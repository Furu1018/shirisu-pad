# しりすこPAD — メンバーがやること (ブロック制・2026-10 から)

PAD の中で入力するものはありません。**前日は Discord に書く。当日は配信を見て凸して、結果のスクショを貼る。** これだけです。

## 前日まで — Discord に 3 つ

1. **出られるブロックと、何凸するか**
   例: 「朝 1・夜 2」「夕方だけ 3」。凸数を決めていなければブロックだけで OK (その中で運営が組みます)。出られない回は「今回は難しい」と一言。
   ブロックは 6 つ (5 時から 4 時間ずつ): 朝 5〜8時 / 午前 9〜12時 / 午後 13〜16時 / 夕方 17〜20時 / 夜 21〜翌0時 / 深夜 翌1〜4時
2. **模擬のスクショ** (編成 5 キャラとダメージが写っているもの)
   属性ごとに 1 つ。最低ラインはキャラ被りなしで 3 属性。**18 時以降に出られる人は、ボス 5 の属性だけ編成を 2 つ** (Lv4 のボス 5 は HP 無限で、2 編成目がそのままスコアになります)
3. **凸先の希望があれば**
   「夕方に 風圧PT の編成① で行きたい」のように。これが「予約」で、組み直しても動きません。無ければ運営が組みます

運営が PAD に登録すると、ホームの **⏰ ユニオンレイド参加可能時間** / **📘 登録された模擬** / **🔒 予約** に出て、通知が届きます。
違っていたら Discord で運営へ (PAD で直す操作はありません)。

## 当日 — 配信を見て、凸して、スクショを貼る

1. 自分のブロックの前に **「🧱 夕方 17〜20時 のあなたの凸が決まりました」** の通知が来ます
   → ホームの **📅 きょうの凸** で「何時に・どのボスへ・どの PT の どの編成で」を見て、**✅ 確認しました** を押す
2. その時刻になったら凸 → **結果の画面のスクショを Discord へ**。PAD に入れるものはありません (運営が取り込むと きょうの凸 に ✓ が付きます)
3. 前のブロックの結果で予定が変わることがあります。**「プランが変わりました」の通知が来たら、もう一度 📅 きょうの凸 を見て ✅**
4. その時刻に行けなくなったら Discord で一言。締め凸 (とどめ) は運営が Discord で声をかけます

配信されるのは **次のブロックのぶんだけ** です。後ろのブロックは、そのブロックの前に運営が配信します。

## PAD で触るのは、この 4 つだけ

- 最初の 1 回: 名乗る・🔔 通知を ON にする (iPhone は先に「ホーム画面に追加」。Safari のタブのままだと通知が来ません)
- 配信を見る (📅 きょうの凸)
- ✅ 確認しました
- 困ったら ヘルプ、または 設定 › 🎮 練習する (メンバー編) で本番と同じ画面を 3 分で試せます
