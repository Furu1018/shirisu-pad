# Discord に貼る文 — S5 の新しい流れ (2026-10-27)

シンプル化 S5 (メンバーの ✓ を無くした / 📅 レイド予定表タブ / ✓ は運営が ⚔️ 戦況 › ✓ 凸の記録 で付ける / 予約の画面を隠した) が入ったあとの、メンバー向け / 運営チーム向けの案内。
S4 版 (`docs/Discordに貼る文_S4_2026-10-27.md`) の代わりにこちらを使う。
決めたこと (10/27 夜・ふるり): メンバーは Discord で凸を報告するだけ・PAD の入力は運営・結果のスクショは Discord に貼り続ける (運営が見て ✓ を付ける)・PAD に数字は入れない。
どちらも Discord の 1 投稿 (2000 字) に収まる。画面の文言は index.html (タブ名・ボタン名) と js/domain/decidePlan.js (通知の題) で確かめた。

## ① メンバー向け

```text
📣 **ユニオンレイドのやり方が変わります (PAD の「📅 レイド予定表」)**

**🗓 前日まで — Discord に書く (PAD への入力はありません)**
1. 出られるブロックと凸数 (例:「朝 1・夜 2」)。出られない回は「今回は難しい」と一言
2. 模擬のスクショ (属性ごとに 1 つ。18 時以降に出る人はボス 5 だけ 2 編成)
3. 凸先の希望があれば (例:「夕方に 風圧PT の編成①」)

ブロックは A・B・C… (既定の 6 つ: A 朝 5〜9時 / B 午前 9〜13時 / C 午後 13〜17時 / D 夕方 17〜21時 / E 夜 21〜翌1時 / F 深夜 翌1〜翌5時。シーズンごとに運営が決めます)

**⚔️ 当日**
1. 「🧱 あなたの凸が決まりました」の通知が来たら、PAD の **📅 レイド予定表** タブを開く
   - ブロックのボタンを押すと、ボスごとに誰が行くかが出ます (★ と太い枠があなた)
   - 下の「みんなの模擬」で、ほかの人の編成とダメージも見られます
   - ホームの 📅 きょうの凸 には、あなたの凸だけが出ます
2. 読んだら **✅ 確認しました** を押す
3. ブロックの時間内に凸したら、**結果の画面のスクショを Discord へ** (PAD では何も押しません。✓ は運営が付けます)
4. 「🔄 あなたの凸が変わりました / 外れました」が来たら、レイド予定表を見直してもう一度 ✅
5. 行けなくなったら Discord で一言

**🔔 はじめに 1 回だけ**: PAD で名乗って通知を ON (iPhone は先に「ホーム画面に追加」。Safari のタブのままだと通知が来ません)
```

## ② 運営チーム向け

```text
👑 **運営チーム向け: 新しい組み方 (凸プランを組む → 決定 → ✓ 凸の記録)**

**🗓 前日まで**
1. **👥 メンバー › ⏰** — Discord の報告どおりに参加可能時間と凸数を登録
2. **👥 › 📸 模擬の取り込み** — スクショを読ませるか ✏️ 手で入力 (人 × 属性の表。赤い枠 = 同じ人の別の編成とキャラが被っている)
3. **🧱 組む › 凸プランを組む** で「A 朝 5〜9時」のボタンを押す
   - 希望がある人は、ピースを選んでボスの行に置く (📌)
   - **🧮 残りを自動で組む** (手で置いた駒は動かない)
4. 見通せるなら 午前・午後…も続けて組む (残り HP を引き継ぐ。5 体撃破したブロックの次から Lv が上がる)
5. **✅ 朝 (・午前…) を決定してメンバーに配信** — 組めたブロックまでまとめて配信、割当のある人に通知。メンバーの 📅 レイド予定表 に出る

**⚔️ 当日 (30 分〜1 時間おき・ブロックの頭ごと)**
1. **⚔️ 戦況 › 🎯 ボス HP を更新する** — BlaBlaLINK のスクショで 5 体を合わせる (「HP更新 ○分前」が 30 分以上で警告色)
2. **⚔️ 戦況 › ✓ 凸の記録** — 組むと同じ盤。Discord に結果のスクショを貼った人の**「未完了」の名前の札を押すと「✓ 完了」** (数字は入れない。押し間違えたら「✓ 完了」の札をもう一度押して取り消し)。✓ が付くと、その人の残り凸と使ったキャラが減る
3. 次のブロックを 🧱 で組む (「要組み直し」が出たら 🧮 をもう一度)
4. **✅ 決定し直す** — 通知は 凸が新しく決まった人・変わった人・外れた人だけ (何も変わらない人には届かず、✅ もそのまま)。済んだ ✓ は残る
5. 必要なときだけ ⚔️ › 🏁 締め凸検索 → Discord で声かけ

**🚫 もう使わないもの**
🔒 凸の予約 (画面から隠しました。希望は Discord → 🧱 で 📌 を置く。前から残っている予約があるときだけ 🧱 組む に出るので、要らなければ「取り下げる」)・📥 結果の取り込み (⚔️ 戦況の下に畳みました)・「詳しく」の従来の算出と配信
```
