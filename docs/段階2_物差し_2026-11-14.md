★ `hit40` は button のほか、開閉の `summary` とチェックの `label` にも付けてよい (2026-11-17 🧱 組む から)。付けるときは、すぐ上下の押せる部品と (40 − 高さ) / 2 以上あける (押せる範囲が縁を取ると、押したつもりの無い開閉・チェックが切り替わる)。付け先は `tests/run-tests.mjs` が一覧で固定する。
★ 練習の場面に出ない部品 (ほかの運営の変更の知らせ・⚠ の「開く」・外した駒の「✕ 外す」・「変わりません」のチェック) は検査に映らない — そこの値は `tests/run-tests.mjs` の「練習の場面に出ない部品も物差しどおり」が固定する。
★ 練習モードに出ない画面 (シート・🧪 テスト稼働中の帯など。👑 マスターは 2026-11-20 から運営役を master にして見る。従来の画面 = member_input=full は 2026-11-16 に撤去した) はこの検査で見られない — そこの `hit40` の付け先は `tests/run-tests.mjs` が固定して見張る。下の「物差しの検査」のスクリプトは、同じものをコンソールで動かす用。

揃え方 (ホームでやった手順): ① そのタブを描く関数と静的な HTML の範囲を決める → ② 範囲の中の `font-size:Npx` を上の寄せ方で機械的に書き換える (一時スクリプト) →
③ CSS のクラス (`(CSS)` と出る外れ) と角丸は 1 つずつ直す → ④ `tests/ruler.mjs` が 0 になるまで → ⑤ 写真で崩れを見る → ⑥ 文字列を固定しているテストを合わせる → ⑦ 更新履歴に 1 項目。
★ 別のタブと共有の関数 (盤・時間割のチップ・`renderTeamSnippet` など) は、表の例外 (9 / 10px) が要る所があるので、範囲に入れずに 1 つずつ見る。

## 進め方

- **タブを 1 つずつ**揃えて公開し、そのたびにふるりが実機で見る。順番は ホーム → 運営 (👥 メンバー → 🧱 組む → ⚔️ 戦況) → レイド予定表 → 分析 → 設定・ヘルプ。
- 文字の大きさはほとんどがインライン style (index.html に 2,716 か所) と、JS が組み立てる HTML の中にある。CSS の上書きでは揃わない — その画面を描く関数の中の数字を直す。
- 見た目が変わるので、タブごとに `data/release-notes.json` に 1 項目 (まとめて 1 項目でもよい)。
- 揃え終わったタブは、下の検査で「外れ 0」になる (表の例外と文字だけのリンクを除く)。段階 2 を進めるときは、これを練習モードの実行テストにして、戻ったら落ちるようにする。

## 物差しの検査 (ブラウザのコンソール / 練習モードで実行)

見本の「揃えたあと」は、開いているタブに次を当てて撮った。`plan.length` が、物差しから外れている部品の数。

```js
(() => {
    const roots = [document.querySelector('.tab-content.active'), document.querySelector('.header'), document.getElementById('bottomNav')].filter(Boolean);
    const els = []; for (const r of roots) { els.push(r); for (const e of r.querySelectorAll('*')) els.push(e); }
    // 表と 1 人 1 行の一覧 (縦に伸ばさない所)。盤の駒・名前の札も含める
    const dense = (e) => !!e.closest('table, .dc-mb-row, [class*="table"], .obr, .obpc, .db-tag');
    const ownText = (e) => [...e.childNodes].some(n => n.nodeType === 3 && n.nodeValue.trim());
    const snapF = (px) => px < 11.3 ? 11 : px < 12.8 ? 12 : px < 15 ? 14 : px < 17.5 ? 16 : px < 24 ? 20 : px;
    const plan = [];
    for (const e of els) {
        const cs = getComputedStyle(e); if (cs.display === 'none') continue;
        const p = {};
        if (ownText(e)) { const px = parseFloat(cs.fontSize); let t = snapF(px); if (dense(e) && px < 11) t = px < 9.75 ? 9 : 10; if (Math.abs(t - px) > 0.01) p.f = t; }
        const r = parseFloat(cs.borderTopLeftRadius); const b = e.getBoundingClientRect();
        if (r > 0 && b.height > 0 && r < Math.min(b.height, b.width) / 2 - 0.5) { const t = Math.min(b.height, b.width) < 24 ? 4 : r <= 10.5 ? 8 : r <= 18 ? 14 : 22; if (t !== r) p.r = t; }
        if (e.matches('button, [role="button"], a.btn, select, input[type="text"], input[type="number"]') && (!dense(e) || e.matches('button.db-tag')) && !e.classList.contains('hit40') && b.height >= 24 && b.height < 40 && b.width >= 44) p.h = 1;   // ⚔️ の押す札は高さだけ dense の例外にしない
        if (p.f || p.r || p.h) plan.push([e, p]);
    }
    return plan;   // [部品, { f: 寄せる先の文字の大きさ, r: 寄せる先の角丸, h: 高さが 40px に足りない }]
})()
```

- 画面写真は `node scripts/survey/shots.mjs . <出力フォルダ>` (全タブ・練習モード)。見本は同じ道具の写しで、上を当てる前とあとを撮った。
- `dense` の一覧は見本を撮ったときの当たりで、足りない所がある (表でないのに行の中にある小さいボタンなど)。タブを揃えるときに、その画面の「縦に伸ばさない所」を決めて足す。
