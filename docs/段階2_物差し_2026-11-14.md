## 物差しの検査 (ブラウザのコンソール / 練習モードで実行)

見本の「揃えたあと」は、開いているタブに次を当てて撮った。`plan.length` が、物差しから外れている部品の数。

```js
(() => {
    const roots = [document.querySelector('.tab-content.active'), document.querySelector('.header'), document.getElementById('bottomNav')].filter(Boolean);
    const els = []; for (const r of roots) { els.push(r); for (const e of r.querySelectorAll('*')) els.push(e); }
    // 表と 1 人 1 行の一覧 (縦に伸ばさない所)。盤の駒・名前の札も含める
    const dense = (e) => !!e.closest('table, .mb-row, .mb-list, [class*="table"], .obr, .obpc, .db-tag');
    const ownText = (e) => [...e.childNodes].some(n => n.nodeType === 3 && n.nodeValue.trim());
    const snapF = (px) => px < 11.3 ? 11 : px < 12.8 ? 12 : px < 15 ? 14 : px < 17.5 ? 16 : px < 24 ? 20 : px;
    const plan = [];
    for (const e of els) {
        const cs = getComputedStyle(e); if (cs.display === 'none') continue;
        const p = {};
        if (ownText(e)) { const px = parseFloat(cs.fontSize); let t = snapF(px); if (dense(e) && px < 11) t = px < 9.75 ? 9 : 10; if (Math.abs(t - px) > 0.01) p.f = t; }
        const r = parseFloat(cs.borderTopLeftRadius); const b = e.getBoundingClientRect();
        if (r > 0 && b.height > 0 && r < Math.min(b.height, b.width) / 2 - 0.5) { const t = Math.min(b.height, b.width) < 24 ? 4 : r <= 10.5 ? 8 : 14; if (t !== r) p.r = t; }
        if (e.matches('button, [role="button"], a.btn, select, input[type="text"], input[type="number"]') && !dense(e) && b.height >= 24 && b.height < 40 && b.width >= 44) p.h = 1;
        if (p.f || p.r || p.h) plan.push([e, p]);
    }
    return plan;   // [部品, { f: 寄せる先の文字の大きさ, r: 寄せる先の角丸, h: 高さが 40px に足りない }]
})()
```

- 画面写真は `node scripts/survey/shots.mjs . <出力フォルダ>` (全タブ・練習モード)。見本は同じ道具の写しで、上を当てる前とあとを撮った。
- `dense` の一覧は見本を撮ったときの当たりで、足りない所がある (表でないのに行の中にある小さいボタンなど)。タブを揃えるときに、その画面の「縦に伸ばさない所」を決めて足す。
