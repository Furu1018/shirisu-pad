## 作り直し方

1. `node src/build_member.mjs <出力先>` / `node src/build_ops.mjs <出力先>` で `slide1.html`… を書き出す (`build_ops` は `build_member` の CSS を読む)。
2. 各 HTML を Chrome のヘッドレスで幅 1080px のまま全体を撮って PNG に。2 倍で撮ったなら `sips --resampleWidth 1080` で 1080px にする。

## 撮影中に見つけたこと (未対応)

- **運営編・前日の練習を途中の課題から始めると、読み込み直しが止まらない。** `?practice=ops-eve&start=request` のように URL で途中から開くと、手前の「nudge (催促)」を済ませる手順 (`js/practice/guide.js` の FF) が無いため fastForward が失敗する。そのたびに URL の `start` がもう一度入るので、読み込み直しが繰り返される。ヘルプ / 設定の「練習する」ボタンから普通に始める分には起きない。
- 配信カードの説明文が「青い縁があなたの凸です」になっているが、実際の縁は紫。
