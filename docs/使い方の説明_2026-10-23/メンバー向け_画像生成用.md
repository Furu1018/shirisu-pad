# しりすこPAD メンバー向け「使い方」説明画像 — 生成用の情報

メンバー (運営ではない人) に、ブロック制になったレイドの PAD の使い方を伝える画像を作るための材料です。
画面は `実機画面_メンバー/` の PNG (練習モードで撮影・スマホ幅 390px の 2 倍解像度) を使います。

---

## 0. 全体の方針

- **読む人**: ユニオンのメンバー。PAD を毎日は開かない人も多い。長い説明は読まれない前提。
- **伝えたいこと (1 行)**: 「出られる時間と何凸するかを入れる → 配信を見て ✅ → 凸したらスクショを Discord へ」の 3 つだけでいい。
- **枚数**: 本編 4 枚 + まとめ 1 枚 (計 5 枚)。Discord に貼る想定。
- **サイズ**: 横 1080px (既存の `docs/最適凸プランの説明_2026-10-23_1.png` / `_2.png` と揃える)。縦は 1 枚 1350〜1920px 目安。
- **見た目**: アプリの色に合わせる。
  - アクセント紫 `#6D3FE8` 前後 (ボタン・「あなた」の枠・凸数の数字)
  - 「出られる」緑 `#16A34A` / 薄緑の背景
  - 「今期 未確認」はオレンジ系のバッジ、「確認済み」は緑のバッジ
  - 背景は白〜ごく薄いグレー。カードは角丸・白
- **画面の貼り方**: 実機画面はスマホの枠 (角丸) に入れるか、カードの切り抜きをそのまま置く。操作する場所に **番号の丸 (①②③) と矢印** を付ける。
- **練習モードの案内**: 最後に「設定 › 🎮 練習する (メンバー編) で本番と同じ画面を約 3 分で試せる」を入れる。

### 言葉の決まり (docs/用語集.md より)

| 使う言葉 | 使わない言葉 |
|---|---|
| ユニオンレイド参加可能時間 (参加可能時間) | 戦闘可能時間 |
| 凸数 / 何凸するか | — |
| ブロック (朝・午前・昼・午後・夕方・夜・深夜) | 時間帯の枠 |
| 配信 / 配信された凸プラン | — |
| きょうの凸 | — |
| 模擬 / 登録された模擬 | — |
| 枠を予約する / 予約 | 申請・約束 |
| 運営が結果を取り込む (✓ が付く) | 凸報告 (メンバー向けには使わない) |
| 締め凸 | 締凸 |

### ブロックの一覧 (図にするとき用)

| ブロック | 時間 |
|---|---|
| 朝 | 5〜8時 |
| 午前 | 9〜11時 |
| 昼 | 12〜14時 |
| 午後 | 15〜17時 |
| 夕方 | 18〜20時 |
| 夜 | 21〜23時 |
| 深夜 | 翌0〜翌4時 |

## 1 枚目: 表紙 + 全体の流れ

**タイトル**: 今期からレイドは「ブロック」で動きます

**サブ**: メンバーがやることは 3 つだけ

**流れの図 (横に 3 つ並べる、またはタテに 3 段)**

1. **前日まで** — ⏰ 参加可能時間と「何凸するか」を入れる
2. **当日、ブロックの前** — 📅 配信を見て「✅ 確認しました」
3. **凸したら** — 結果の画面のスクショを Discord へ

**補足 (小さく)**
- 模擬は今までどおり Discord にスクショを貼るだけ。運営が PAD に登録します。
- 運営は **ブロックごと** に、そのブロックに出られる人で凸を組み、ブロックの前に配信します。

**使う画面**: `01_ホーム.png` (ホーム全体のイメージとして小さく)

---

## 2 枚目: ① 参加可能時間と凸数を入れる (前日まで)

**タイトル**: ① 出られるブロックと「何凸するか」を入れる

**手順**

1. ホームの「⏰ ユニオンレイド参加可能時間」で **「変更する ›」** を押す
   - 画面: `02_参加可能時間カード.png` — 右上の「変更する ›」に ① を付ける。「今期 未確認」のバッジも指す
2. 1 時間でも出られるブロックをタップして **ON (✓ 出られる)** にする
   - 画面: `03_参加可能時間シート.png` — 「出られるブロック」の夕方・夜が緑になっているところに ②
3. 「何凸するか」で **＋ / −** を押す。入れなければ「おまかせ」(運営がそのブロックのどこかに割り当てる)
   - 画面: `04_参加可能時間シート_夜2.png` — 夜「2 凸」・合計 2/3 に ③
4. いちばん下の **「この時間で参加します」** を押す (出られない回は「今回は難しい」)
   - 画面: `04b_参加可能時間シート_確定ボタン.png` — 紫のボタンに ④
5. ホームのバッジが **「今期 確認済み」** になれば OK。凸数も出ます
   - 画面: `02b_参加可能時間カード_確認後.png`

**ポイント (囲みで)**
- 凸数を入れたブロックには、運営はその数より多く割り当てません。
- 合計は 3 凸まで。
- 毎期 1 回「この時間で参加します」を押す (前期と同じ時間でも押す)。

---

## 3 枚目: ② 配信を見て「✅ 確認しました」(当日)

**タイトル**: ② ブロックの前に配信を見て「✅ 確認しました」

**手順**

1. 当日、出られるブロックの前にホームを開く。「次にやること」と「📅 きょうの凸」に自分の凸が出ています
   - 画面: `06b_次にやること_当日.png` (「🔥 レイド当日! 残り3凸」)
2. **📅 きょうの凸** で「何時に・どのボスへ・どの PT (編成) で」行くかを見る
   - 画面: `08_きょうの凸_配信後.png` — 夜「21時 B1 ドリアン Lv1 / 水冷PT 編成①」に ②
   - 「まだ決まっていません」= そのブロックはまだ配信前。運営がブロックの前に配信します
3. 「配信された凸プラン」の下の **「✅ 確認しました」** を押す
   - 画面: `07c_確認しましたボタン.png` → 押すと `07b_確認済み.png`
   - 押しておくと、レイド中にプランが組み直されたとき通知でお知らせが来ます

**参考 (余白があれば)**
- `07_配信カード.png` — 盤の見方: 枠の長さ = ボスの残り HP、ピースの幅 = 模擬ダメージの目安、紫の縁 = あなたの凸、角の数字 = 時刻
- 配信されるのは **次のブロックのぶんだけ**。後ろのブロックは、そのブロックの前に配信されます。

---

## 4 枚目: ③ 凸したら Discord へ

**タイトル**: ③ 凸したら、結果の画面のスクショを Discord へ

**本文**
- 割り当てられた時刻になったら、ゲームで凸をする
- 結果の画面のスクショを **Discord** に貼る (PAD には何も入れなくていい)
- 運営がスクショを見て結果を取り込むと、📅 きょうの凸に **✓** が付きます

**使う画面**: `05_きょうの凸_配信前.png` (左・0/3 凸 済み) → `12_きょうの凸_取り込み後.png` (右・1/3 凸 済み、「✓ B1 ドリアン Lv1 · 24.6B」)
左右に並べて「→」でつなぐと分かりやすい。

**ポイント**
- ボスの残り HP は運営が見ています。
- 時刻に行けなくなったら、Discord で運営に一言。

---

## 5 枚目: まとめ + 知っておくと便利なこと

**タイトル**: まとめ

**3 行まとめ (大きく)**
1. 前日までに ⏰ 参加可能時間と凸数 →「この時間で参加します」
2. 当日、ブロックの前に 📅 きょうの凸 を見て「✅ 確認しました」
3. 凸したら スクショを Discord へ (✓ が付けば OK)

**知っておくと便利 (小さめ・2 つ)**

- **📘 登録された模擬** — 運営が Discord の模擬のスクショから登録したもの。直したいときは Discord に模擬のスクショを出し直す
  - 画面: `09_登録された模擬.png`
- **🔒 枠を予約する** (希望がある人だけ) — 「このブロックにこの PT で凸したい」を先に出せる。運営が承認すると予約が決まり、組み直しても動かない。時刻は運営がブロックの中で決める。予約しなくても、運営が参加可能時間と凸数から割り当てる
  - 画面: `10_予約カード.png` / `11_枠を予約するシート.png` (どの編成で → どのブロックで → 「この内容で予約する」)

**練習モード (最後に目立つように)**
- 設定 › **🎮 練習する (メンバー編)** — 本番と同じ画面を、練習用のデータで約 3 分。本番には反映されません
  - 画面: `13_設定_練習する.png`
