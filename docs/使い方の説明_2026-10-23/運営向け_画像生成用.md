# しりすこPAD 運営向け「操作」説明画像 — 生成用の情報

運営担当 (運営タブを使う人) に、ブロック制のレイドを回す操作を伝える画像を作るための材料です。
メンバー向け (`メンバー向け_画像生成用.md`) と対になります。見た目・サイズ・言葉の決まりは同じです。

実機画面は `実機画面_運営/` に、練習モード (運営編・前日 / 当日) で撮影して入れます (このあと撮影)。下の各枚にファイル名の予定を書いています。

---

## 0. 全体の方針

- **読む人**: 運営担当。PAD の画面には慣れているが、ブロック制の回し方は今期が初めて。
- **伝えたいこと (1 行)**: 「前日に朝のぶんを組んで配信 → 当日はブロックごとに ⚔️ HP → 📥 取り込み → 🧱 組む → 📤 配信 を繰り返す」。
- **枚数**: 6 枚。Discord の運営スレに貼る想定。
- **サイズ・見た目**: メンバー向けと同じ (横 1080px、アクセント紫 `#6D3FE8`、角丸の白カード)。タグは「しりすこPAD · 運営向け操作 (n/6)」。
- **画面の貼り方**: メンバー向けと同じく、手順の番号 + 画面の切り抜きを左右に並べる。
- **練習モードの案内**: 最後に「設定 › 🎮 練習する (運営編・前日 / 当日)」。

### 言葉の決まり (docs/用語集.md より・運営向けで特に使うもの)

| 使う言葉 | 使わない言葉 |
|---|---|
| 配信 / 〇〇のぶんを配信 | — |
| 📌 仮置き (運営の下書き・本人には見えない) / 🔒 確定 | 📌 固定 / 運営の固定 |
| 予約 / 承認待ち / 予約済み (🔒 予約) | 申請 / 約束 / 引き受けた凸 |
| 結果の取り込み (Discord の凸の結果のスクショを登録) | 凸報告 / 代理凸 |
| 模擬の取り込み (Discord の模擬のスクショを登録) | 模擬の提出 |
| 締め凸 / 締め凸検索 | 締凸 / 締め凸候補検索 / 締め凸の依頼 |
| 運営 / 運営担当 / 👑 マスター | — |

### 運営タブの中のタブ (カードはいつも同じ場所)

| タブ | 中身 |
|---|---|
| 👥 メンバー | メンバー状況 (模擬 / SLv / 時間帯・凸数 / 通知 / B5×2) と催促・📸 模擬の取り込み・一斉通知 |
| 🧱 組む | このブロックの手順・🔒 凸の予約 (承認)・最適凸プラン算出 (🧱 盤 / 🗓 時間割) |
| ⚔️ 戦況 | ボス状況 (HP の更新)・締め凸検索・📥 結果の取り込み |
| 👑 マスター | シーズン制御・育成データ・バックアップ・任命など (ふるりだけ) |

- 開いたときのタブは日によって変わる (前日まで 👥 / 当日 ⚔️)。
- いちばん上に「いちばん急ぐこと」が 1 つ出る。タブの横の数字は手を打つべき件数。

## 1 枚目: 表紙 + 運営の 1 日

**タイトル**: ブロック制レイドの回し方 (運営)

**サブ**: 前日に「朝」を配信。当日はブロックごとに同じ 4 手順を繰り返します。

**図 A: 運営タブの地図 (4 つ横並び)**
👥 メンバー / 🧱 組む / ⚔️ 戦況 / 👑 マスター — それぞれ 1 行の説明 (上の表)。

**図 B: タイムライン (横長)**
- **前日**: 模擬の取り込み・催促 → 🧱 朝を組む → 予約の承認 → 📤 朝のぶんを配信
- **当日・各ブロックの頭** (朝・午前・昼・午後・夕方・夜・深夜): ⚔️ HP → 📥 結果の取り込み → 🧱 組む → 📤 配信 → (残りが少なければ) 🏁 締め凸検索

**補足 (小さく)**
- 配信されるのはそのブロックのぶんだけ。後ろのブロックは、そのブロックの前に配信する。
- 交代するときは、タブの数字と「いちばん急ぐこと」から続ける。

**使う画面**: `ops01_運営タブ_上部.png` (いちばん急ぐこと + タブの並び)

## 2 枚目: 前日 ① メンバーの準備をそろえる (👥 メンバー)

**タイトル**: 前日 ① 模擬と参加可能時間をそろえる

**手順**
1. **📸 模擬の取り込み** — Discord に貼られた模擬のスクショを登録する (メンバーのホームの「📘 登録された模擬」に出る)
2. **メンバー状況** で、模擬 / 参加可能時間と凸数 / 通知 がまだの人を見る
3. **📣 未提出の人に催促する** → 宛先と文面を確かめて「送信する」
   - 画面: `ops02_催促ボタン.png` → `ops03_催促の送信確認.png`
4. 全員に伝えたいことは **一斉通知** (運営も使える)

**ポイント (囲み)**
- 催促は通知を購読している人にだけ届く。届かない人は Discord で声をかける。
- 参加可能時間に凸数を入れた人には、そのブロックでその数より多く割り当てられない (算出が自動で守る)。
- 時間を登録していない人は算出の候補に入らない。

## 3 枚目: 前日 ② 🧱 朝のブロックを組む

**タイトル**: 前日 ② 🧱 朝のブロックを組む

**手順**
1. **🧱 組む** タブを開く。頭に「このブロックの手順」が並び、いまの手順が光る
   - 画面: `ops04_このブロックの手順.png`
2. 対象を **「🧱 ブロックの人」** にする (前日は「朝」が選ばれている)
3. **「🧮 この条件で算出」** を押す
   - 画面: `ops05_算出の条件.png`
4. **🧱 盤** で見る: 枠の長さ = ボスの残り HP、ピースの幅 = ダメージの目安。足りないボスには候補が出る
   - 画面: `ops06_盤.png`
5. 置きたい人がいれば **📌 仮置き** — ピース (または 🧩 模擬ピース) を押す → 光ったマスを押す → 自動で算出し直し
   - 画面: `ops07_時間割_仮置き.png`

**ポイント (囲み)**
- 📌 は運営の下書き。本人には見えず、配信したときに割当として届く。
- 3 凸埋まっている人に置くと 🔁 入れ替えの確認が出る (迷ったら「外す凸は算出に任せる」)。
- 自動で効くもの: 🔒 予約・🚫 除外・✋ 難しい・本人の凸数・ボス 5 の 2 編成目は Lv4 だけ。

## 4 枚目: 前日 ③ 予約を承認して、朝のぶんを配信

**タイトル**: 前日 ③ 予約を承認 → 📤 朝のぶんを配信

**手順**
1. メンバーから予約が届くと運営あてに通知が鳴る。**🔒 凸の予約** のカードを開く
2. **「承認する」** → OK。承認した予約を入れて組み直し、**差分 (誰の割当が変わるか)** が出る
   - 画面: `ops08_予約の承認.png` → `ops09_組み直しの差分.png`
3. **「📤 朝のぶんを配信」** → OK。押すまでメンバーには見えない
   - 画面: `ops10_配信ボタン.png`
4. Discord の運営スレに「朝 配信した」と 1 行

**ポイント (囲み)**
- 承認すると本人に通知が届く。予約は組み直しても動かない。
- 置けなかった予約 (未達) は必ず画面に出る。運営が解除しないと、その人の枠を押さえたままになる。
- 配信すると、そのブロックに割当のある人のホームに割当が出て「あなたの凸」の通知が届く。同じブロックの配信し直しは、割当が変わった人にだけ届く。
- 「配信中止」は削除ではなく凍結 (メンバーには前の割当と「組み直し中」の帯)。

## 5 枚目: 当日 ブロックの頭にやる 4 手順

**タイトル**: 当日 ブロックごとに ⚔️ → 📥 → 🧱 → 📤

**図: 4 手順のサイクル (円 または 横 4 つ + 「次のブロックへ」の矢印)**

1. **⚔️ ボスの HP をゲームと合わせる** — ⚔️ 戦況 の「🎯 ボス HP を更新する」→ 残HPを入れて「保存」
   - 画面: `ops11_ボスHP更新.png`
   - 残HP が 0 になる保存は撃破として検知される (通知が飛ぶ)。数字を確かめてから押す
2. **📥 前のブロックの結果を取り込む** — ⚔️ 戦況 の「📥 結果の取り込み」。「⏰ 結果がまだの凸」の「📥 取り込む」→ ダメージ → 「登録する」
   - 画面: `ops12_結果がまだの凸.png` → `ops13_結果の取り込み.png`
   - スクショを選ぶと ボス・ダメージ・使ったキャラ を読み取れる (PC はカードにスクショを落とすだけ)
   - 凸していなかった人は「凸していない」→ 残り凸のまま次のブロックで組み直す
3. **🧱 そのブロックを組む** — 前日と同じ (対象「🧱 ブロックの人」→ 算出)。前に配信した割当は尊重される
4. **📤 そのブロックのぶんを配信** → 運営スレに 1 行

**ポイント (囲み)**
- 古い HP のまま組むと、無駄凸や取りこぼしが出る。必ず ⚔️ から。
- ⚔️ のタブの横の数字 = 確認していない凸 + 結果がまだの凸。

## 6 枚目: 締め凸検索・一気に組む・練習

**タイトル**: 知っておくと便利

**🏁 締め凸検索 (⚔️ 戦況)**
- 残りが少ないボスのカードで「締め凸検索」→ 「今打てる手」と「待って打てる手」が並ぶ
- 「いま打つか、待つか」を読んで、**📋 名前と文面をコピー** → Discord で声をかける (PAD からは頼まない)
- やってもらえることになったら、盤に置いて 🔒 確定 → 配信
- 手詰まり (今も待つも無い) なら 🧱 組む で組み直す
- 画面: `ops14_締め凸検索.png`

**🧱 残りのブロックを一気に組む (🧱 組む)**
- 模擬が早くそろったとき。いまのブロックから最後まで、前のブロックが模擬どおり削れたと仮定して順に組み、ブロックごとに配信する
- 仮定して組んだぶんには 🔭 予想 の印が付く。通知は人ごとに 1 通
- 実際の結果でずれたら、そのブロックか次のブロックの頭で組み直す (変わった人には通知が届く)
- 画面: `ops15_一気に組む.png`

**🎮 練習 (最後に目立つように)**
- 設定 › **🎮 練習する (運営編・前日)** — 催促 → 🧱 朝を組む → 📌 → 予約の承認 → 朝のぶんを配信
- 設定 › **🎮 練習する (運営編・当日)** — 夕方のブロックの頭: ⚔️ HP → 📥 結果の取り込み → 🧱 夕方を組む → 配信 → 締め凸検索
- 本番と同じ画面を練習用のデータで。本番には反映されない
- 画面: `ops16_設定_練習する_運営.png`
