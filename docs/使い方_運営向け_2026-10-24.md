# しりすこPAD — 運営チームがやること (ブロック制・2026-10 から)

**メンバーは Discord に書くだけ。PAD への登録はぜんぶ運営がやる。** 当日はブロックの頭ごとに 4 つの手順を繰り返す。
言葉は `docs/用語集.md`。流れの元は `docs/ブロック制_運用の見直し_2026-10-24.md` (§6 に決めたこと)。

## 運営タブの地図

運営担当 (👑 マスターが任命) で名乗ると下メニューに **運営** が出る。中のタブは 4 つで、**カードはいつも同じタブ**にある。

| タブ | 置いてあるもの |
|---|---|
| 👥 メンバー | メンバー状況 (模擬 / SLv / 時間帯・凸数 / 通知 / B5×2) と催促 ・ 📸 模擬の取り込み ・ 📣 Discord 用の文面 ・ 一斉通知 |
| 🧱 組む | このブロックの手順の帯 ・ 🔒 凸の予約 (＋ 予約を登録) ・ 最適凸プラン算出 (🧱 盤 / 🗓 時間割 / リスト・🧩 模擬ピース) ・ 📤 配信 ・ 残りのブロックを一気に組む |
| ⚔️ 戦況 | ボス状況 (🎯 ボスHP更新) ・ 📥 結果の取り込み ・ 締め凸検索 |
| 👑 マスター | シーズン制御 ・ 任命 ・ バックアップ / 復元 ・ 版のしめ切り (ふるりだけ) |

開いたときのタブは日で変わる (前日まで 👥 / 当日 ⚔️)。いちばん上の **「いちばん先に」** が、いま最初にやることを 1 つ出す。タブの横の数字は手を打つべき件数。
交代したら、ここから続ける。

## 前日より前

- 👑 シーズンを作る (ボス・属性・HP・ハード日)。ブロックの区切りは既定の 7 つ (変えるなら ✏️ シーズン編集)
- 🔔 通知の疎通確認を送る (レイドの 2 日前から。届いた人 / まだの人 が 👥 に出る)
- メンバー向けの文章を Discord にピン留め (👥 メンバー › **📣 Discord 用の文面** からコピー、または `docs/使い方_メンバー向け_2026-10-24.md`)

## 前日 — Discord の報告が来たら、人ごとに PAD へ

1. **⏰ 参加可能時間と凸数を登録** — 👥 メンバー状況の行の **⏰**、または 📸 模擬の取り込みの「時間を登録」。本人のシートと同じ部品 (ブロックのチップ + 凸数 + 今回は難しい) に「👑 運営の登録: ○○ さん」と出る。
   前回の登録が既定で入っているので、変わった所だけ直して **「この時間で参加します」**。凸数が無ければ入れない (= おまかせ)。
2. **📸 模擬を登録** — 👥 メンバー › 📸 模擬の取り込み。「誰の模擬か」→ スクショを選ぶ (PC はカードに落とす / 貼り付け)。保存先 (編成① / ②) は自動で選ばれる (直せる)。
   届いていない人と、その人の締め切り (〆 = 最初に出られるブロックの前) が並ぶ。18 時以降に出られる人は ボス 5 の 2 編成目が足りなければここに残る。
3. **🔒 予約を登録 (希望が書かれた人だけ)** — 📸 の保存直後の **「🔒 この編成で予約する」** → ブロックを選ぶ。あとからは 🧱 組む › 🔒 凸の予約 の **「＋ 予約を登録」** (誰が・どの編成・どのブロック)。
   登録すると本人に通知が届き、本人のホームに 🔒 で出る。予約は組み直しても動かない。時刻はブロックの中で算出が決める。
4. **報告の無い人に催促** — 「いちばん先に」の **📣 未提出の人に催促する** → 宛先と文面を確かめて送信。文面は「Discord で教えてください」。
   催促は通知を購読している人にだけ届く。届かない人は Discord で直接。時間の報告が無い人は算出の候補に入らない (👥 に「時間 未登録」)。
5. **🧱 朝のブロックを組む** — 🧱 組む › 対象「🧱 ブロックの人」(前日は「朝」が選ばれている) → **🧮 この条件で算出** → 🧱 盤で確かめる。
   足りないボスには候補が出る。手で置くなら ピース (🧩 模擬ピース) を押す → 光ったマスを押す (📌 仮置き・本人には見えない・自動で算出し直し)。
   置ける場所が無い駒を選ぶと理由が出る (3 凸を使い切った / 属性のボスがいない / 時刻のマスが無い / 時間に合わない)。🧩 の各ピースにも「⚠ 置ける所なし: 理由」。
6. **📤 朝のぶんを配信** → 確認 → OK。朝に割当のある人のホームに出て「あなたの凸」の通知が届く。Discord の運営スレに「朝 配信した」と 1 行。
   模擬が早くそろっていれば **🧱 残りのブロックを一気に組む** で 1 日ぶんの予想 (🔭) を先に配信できる (ずれたら次のブロックの頭で組み直す)。

## 当日 — ブロックの頭ごとに 4 つ (🧱 組む の手順の帯のとおり)

1. **⚔️ ボスの HP をゲームと合わせる** — 「いちばん先に」の **🎯 ボス HP を更新する** (⚔️ 戦況 › ボス状況)。
   BlaBlaLINK のボス一覧のスクショを 選ぶ / 落とす / 貼り付け (PC) → 5 体を読み取り → 行に **いまの値との差分** (「47.06 → 40B (−7.06)」/「のまま」/「読めず (手で入力)」) → **⏬ 読み取った値を保存**。
   残 HP が 0 になる保存は撃破として検知される (通知が飛ぶ)。増えていたら読み違いを疑う (レベルが開いた直後は別)。古い HP のまま組むと無駄凸や取りこぼしが出るので、必ずここから。
2. **📥 前のブロックの結果を取り込む** — ⚔️ 戦況 › 📥 結果の取り込み。「⏰ 結果がまだの凸」の **📥 取り込む** → スクショを選ぶ (ボス・ダメージ・使ったキャラを読み取る) か ダメージを手で入力 → **登録する**。
   登録すると ✓ 確認済みになり、ボスの残 HP もダメージぶん減る (スクショに残 HP があればその値)。凸していなかった人は **「凸していない」** (残り凸のまま次のブロックで組み直す)。聞きたいときは **📋 聞く** で文面をコピーして Discord へ。
3. **🧱 そのブロックを組む** — 🧱 組む › 対象「🧱 ブロックの人」(いまのブロックが選ばれている) → 🧮 算出 → 盤で確かめて必要なら 📌。前に配信した割当は尊重される。
4. **📤 そのブロックのぶんを配信** → 運営スレに 1 行。
   同じブロックを配信し直したときは、**割当が変わった人にだけ** 通知が届く (✅ を押していた人には「確認したあとにプランが変わりました」、押していない人には「まだ確認していませんが、プランが変わりました」。割当が消えた人にも)。
5. 残りが少ないボスは **🏁 締め凸検索** (⚔️ 戦況) — 「いま打つか、待つか」を読んで **📋 名前と文面をコピー** → Discord で声をかける (PAD からは頼まない)。やってもらえることになったら、盤に置いて 🔒 確定 → 配信。

## 知っておくこと

- **1 ブロックは 1 人が組む** (📌 は誰が置いてもよい)。共有されるのは DB にあるもの (📌・🔒・HP・凸の結果・模擬・時間・配信)。算出の結果と条件パネルの選択は端末の中だけ。
  同じ条件・同じ 📌 で算出すれば別の端末でも同じ盤面になる。配信の直前に「別の運営が配信していないか」を照合するので、相手の約束を知らずに上書きすることはない。
- **置けなかった予約 (未達) は必ず画面に出る**。運営が解除しないと、その人の枠を押さえたままになる。
- **「配信中止」は削除ではなく凍結** (メンバーには前の割当と「組み直し中」の帯)。新しい配信を入れれば解除される。
- 誤って登録した凸は 📥 結果の取り込み › 登録された凸 の ✏️ 編集・削除で直す。
- メンバーに PAD の入力はない。「違っていたら Discord で運営へ」と伝えてある。本人の時間シート・枠を予約する は従来の画面 (✏️ シーズン編集 › member_input=full) でだけ出る。
- 練習: 設定 › **🎮 練習する (運営編・前日 / 当日)** — 本番と同じ画面を練習用のデータで、各 5 分。前日は 催促 → ⏰ 報告を登録 → 🔒 希望を予約に → 🧱 朝を組む → 📌 → 配信、当日は ⚔️ HP → 📥 結果の取り込み → 🧱 夕方を組む → 配信 → 締め凸検索。
