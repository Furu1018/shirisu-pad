# しりすこPAD — 運営チームがやること (ブロック制・2026-10 から)

**メンバーは Discord に書くだけ。PAD への登録はぜんぶ運営がやる** (凸の ✓ も)。当日はブロックの頭ごとに 🎯 HP → ✓ 凸の記録 → 🧱 組む → ✅ 決定 を繰り返す (必要なら締め凸検索)。2026-10-27 のシンプル化 (S1〜S5) のあとの形。
言葉は `docs/用語集.md`。流れの元は `docs/ブロック制_運用の見直し_2026-10-24.md` (§6 に決めたこと)。

## 運営タブの地図

運営担当 (👑 マスターが任命) で名乗ると下メニューに **運営** が出る。中のタブは 4 つで、**カードはいつも同じタブ**にある。

| タブ | 置いてあるもの |
|---|---|
| 👥 メンバー | メンバー状況 (模擬 / SLv / 時間帯・凸数 / 通知 / B5×2) と催促 ・ 📸 模擬の取り込み ・ 📣 Discord 用の文面 ・ 一斉通知 |
| 🧱 組む | **凸プランを組む** (6 ブロックのボタン → ピースを置く 📌 → 🧮 残りを自動で組む → ✅ 決定)・従来の算出と配信は「詳しく」に畳んである |
| ⚔️ 戦況 | ボス状況 (見出しの 🎯 ボス HP を更新する) ・ **✓ 凸の記録** ・ 締め凸検索 ・ 📥 結果の取り込み (畳んである・数字を入れたいときだけ) |
| 👑 マスター | シーズン制御 ・ 任命 ・ バックアップ / 復元 ・ 版のしめ切り (ふるりだけ) |

開いたときのタブは日で変わる (前日まで 👥 / 当日 ⚔️)。いちばん上の **「いちばん先に」** が、いま最初にやることを 1 つ出す。タブの横の数字は手を打つべき件数。
交代したら、ここから続ける。

## 前日より前

- 👑 シーズンを作る (ボス・属性・HP・ハード日)。ブロックの区切りは既定の 6 つ (5 時から 4 時間ずつ) (変えるなら ✏️ シーズン編集)
- 🔔 通知の疎通確認を送る (レイドの 2 日前から。届いた人 / まだの人 が 👥 に出る)
- メンバー向けの文章を Discord にピン留め (👥 メンバー › **📣 Discord 用の文面** からコピー、または `docs/使い方_メンバー向け_2026-10-24.md`)

## 前日 — Discord の報告が来たら、人ごとに PAD へ

1. **⏰ 参加可能時間と凸数を登録** — 👥 メンバー状況の行の **⏰**。**運営の自分の時間も自分の行の ⏰ から** (ホームの ⏰ のカードは見るだけ・変更の入口は出さない)。本人のシートと同じ部品 (ブロックのチップ + 凸数 + 今回は難しい) に「👑 運営の登録: ○○ さん」と出る。
   前回の登録が既定で入っているので、変わった所だけ直して **「この時間で参加します」**。凸数が無ければ入れない (= おまかせ)。
2. **📸 模擬を登録** — 👥 メンバー › 📸 模擬の取り込み。「誰の模擬か」→ スクショを選ぶ (PC はカードに落とす / 貼り付け)。保存先 (編成① / ② / ③) は自動で選ばれる (同じ編成ならその枠 / 空いている枠の若いほう / 全部埋まっていればダメージの低い枠。直せる)。
   届いていない人と、その人の締め切り (〆 = 最初に出られるブロックの前) が並ぶ。18 時以降に出られる人は ボス 5 の 2 編成目が足りなければここに残る。
3. **報告の無い人に催促** — 「いちばん先に」の **📣 未提出の人に催促する** → 宛先と文面を確かめて送信。文面は「Discord で教えてください」。
   催促は通知を購読している人にだけ届く。届かない人は Discord で直接。時間の報告が無い人は組む候補に入らない (👥 に「時間 未登録」)。
4. **🧱 朝を組む** — 🧱 組む › 凸プランを組む の **「朝 5〜8時」** のボタン。下に「この時間帯に出られる人の模擬」のピースが並ぶ (🔒 = この時間帯しか出られない人)。
   - 凸先の希望が Discord で来た人は、ピースを押してボスの行を押す (📌 仮置き・本人には見えない)。幅 = ダメージで、ボスの残り HP が減るのが見える。駒は **✕** で 1 個ずつ外せる (手で置いた駒も自動の駒も・下のピースをもう一度押しても同じ)。外した駒は 🧮 では使わない (置き直すか「このブロックをやり直す」で戻る)
   - **🧮 残りを自動で組む** (手で置いた 📌 は動かさない)
   - 置けないピースは理由が出る (使ったキャラ・被りの相方を置いた・凸なし・属性が効かない・撃破済み)
5. 見通せるなら **午前・午後…も続けて組む** (前のブロックを組んだとおりに削れたとして、残り HP を引き継ぐ。5 体撃破したブロックの次から Lv が上がる)
6. **✅ 朝 (・午前…) を決定してメンバーに配信** → 確認 → OK。メンバーの **📅 レイド予定表** に出て、割当のある人に「あなたの凸が決まりました」の通知。Discord の運営スレに 1 行。

## 当日 — 30 分〜1 時間おき・ブロックの頭ごと

1. **🎯 ボスの HP を BlaBlaLINK と合わせる** — ⚔️ 戦況 › ボス状況の見出しの **🎯 ボス HP を更新する** (30 分以上古くなると「いちばん先に」にも出る)。
   BlaBlaLINK のボス一覧のスクショを 選ぶ / 落とす / 貼り付け (PC) → 5 体を読み取り → 行に **いまの値との差分** (「47.06 → 40B (−7.06)」/「のまま」/「読めず (手で入力)」) → **⏬ 読み取った値を保存**。
   ✓ にはダメージが入らないので、PAD の残 HP はここで合わせる。残 HP が 0 になる保存は撃破として検知される (通知が飛ぶ)。古い HP のまま組むと無駄凸や取りこぼしが出る。
2. **✓ 凸の記録** — ⚔️ 戦況 › ✓ 凸の記録。組むと同じ盤 (ブロックのボタン → ボスの行の帯 + 名前の札)。Discord に結果のスクショを貼った人の**名前の札**を押すと「未完了」が「✓ 完了」に (札が塗りになる・数字は入れない)。押し間違えたら「✓ 完了」の札をもう一度押して取り消し (誰の凸かの確認が出る)。
   ✓ が付くと、その人の残り凸と使ったキャラが減り、次のブロックを組むときに正しくなる。もう数字で報告されている凸に重ねるときだけ確認が出る。
3. **🧱 いまのブロックを組み直す** (ずれたとき・先のブロックを組むとき) — 「要組み直し」が出たら 🧮 をもう一度。済んだ ✓ は動かない。
4. **✅ 決定し直す** — 通知は 凸が新しく決まった人・変わった人・外れた人だけ (何も変わらない人には届かず、✅ もそのまま)。
5. **(必要なときだけ)** 残りが少ないボスは **🏁 締め凸検索** (⚔️ 戦況) — 「いま打つか、待つか」を読んで **📋 名前と文面をコピー** → Discord で声をかける (PAD からは頼まない)。

## 知っておくこと

- **1 ブロックは 1 人が組む** (📌 は誰が置いてもよい)。共有されるのは DB にあるもの (📌・🔒・HP・凸の結果・模擬・時間・配信)。算出の結果と条件パネルの選択は端末の中だけ。
  同じ条件・同じ 📌 で算出すれば別の端末でも同じ盤面になる。配信の直前に「別の運営が配信していないか」を照合するので、相手の約束を知らずに上書きすることはない。
- **決定は「見通しのつくところまで」**。組めたブロックまでを決め、先のブロックは見通しがついたら組んで決定し直す (過ぎたブロック・組み直していないブロックは前の決定のまま)。
- 組んだ結果は決定するまでその端末だけ。📌 は DB に残る (別の運営にも見える)。決定の直前に「別の運営が決定していないか」を照合する。
- 誤って付けた ✓ は ✓ 凸の記録で、その「✓ 完了」の札をもう一度押して取り消す。数字で登録した凸は 📥 結果の取り込み › 登録された凸 の ✏️ 編集・削除で直す。
- メンバーに PAD の入力はない (✓ も押さない)。「違っていたら Discord で運営へ」と伝えてある。予約の画面・本人の時間シート は従来の画面 (✏️ シーズン編集 › member_input=full) でだけ出る。
- 練習: 設定 › **🎮 練習する (運営編・前日 / 当日)** — 本番と同じ画面を練習用のデータで、各 5 分。前日は 📸 模擬を登録 → 🧱 朝を組む (📌 → 自動) → 午前も → ✅ 決定、当日は 🎯 HP → ✓ 凸の記録 → 🧱 夕方を組み直す → ✅ 決定し直す → 締め凸検索。
