## 作り直し方

1. 画面を撮り直す (練習モード `?practice=member` / `ops-eve` / `ops-day`・390×844・2 倍・案内の帯は消す)。撮り方の例は 2026-10-23 の `../使い方の説明_2026-10-23/README.md` と同じ (scratchpad の cdp スクリプト)。`実機画面/` に置く
2. `node src/build_a4.mjs` → `メンバー向け_A4.html` / `運営向け_A4.html` (文面と切り抜きは build_a4.mjs の中)
3. `CDP_PORT=9336 node src/render_a4.mjs <cdp.mjs>` → PNG (2 倍) と PDF (Chrome の `--print-to-pdf`)。`.page` の高さが 1123px (A4) を超えていないか・画像が読めているか (imgs: 0) を出力で確かめる

## 注意

- 🎯 ボスHP更新の画面の「差分」(47.06 → 40B など) は、練習モードでは OCR が動かないので **本物の表示関数に例の数字を渡して描いたもの** (表示例)。それ以外はすべて練習モードの実データで撮った本物の画面
- 画面や流れを変えたら、この A4 と文章版、アプリ内の 📣 Discord 用の文面 を一緒に直す (CLAUDE.md)
