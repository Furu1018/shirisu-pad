# しりすこPAD 用語集 (画面の呼び方の正本)

2026-10-23 ユーザー決定「全体的に語句とか機能の呼び方を統一したほうが分かりやすい」。
画面・通知・ヘルプ・ツアー・練習モードの文言は **この表の「呼び方」** で書く。「使わない言い方」を画面に出さない
(コードのコメント・変数名・DB の列は変えなくてよい)。

| 呼び方 | 意味 | 使わない言い方 |
|---|---|---|
| **ユニオンレイド参加可能時間** (短く: **参加可能時間**) | 本人が登録する、レイドの日に出られる時間 (ブロックのチップで ON / OFF) | 戦闘可能時間 / 出られる時間 / 凸可能時間 |
| **凸数** | 参加可能時間のブロックごとに何凸するか (合計 3 まで・入れなければおまかせ) | — |
| **ブロック** | 朝 / 午前 / 昼 / 午後 / 夕方 / 夜 / 深夜 (レイドの日 5時〜翌4時の区切り) | — (1 時間の区切りは「時刻」) |
| **今期の確認** | シーズンごとの「この時間で参加します / 今回は難しい」 | — |
| **模擬** | 模擬戦のダメージと編成。Discord にスクショを貼る → 運営が登録 → ホームの「📘 登録された模擬」 | 模擬戦データ / 提出 (メンバーに向けて) |
| **PT / 編成①・編成②** | 属性ごとの編成 (1 属性に 2 つまで)。「灼熱PT 編成②」 | — |
| **配信** | 運営が次のブロックのぶんを組んでメンバーに出すこと | — |
| **あなたの凸** (一覧は **📅 きょうの凸**) | 配信で決まった自分の凸 (いつ・どのボス・どの PT の どの編成) | わたしの凸 / あなたの3凸 (シンプルな画面) |
| **予約** (入口は **枠を予約する**) | 本人が出す「このブロックに この PT で凸したい」。運営が承認すると決まる | 申請 / 約束 / 引き受けた凸 |
| **承認待ち** / **🔒 予約** | 予約の状態 (出した → 運営が承認した) | 申請中 / 固定中 / 予約で固定 |
| **📌 仮置き** | 運営が盤に置いた下書き (本人には見えない)。**🔒 確定** で予約に | 📌 固定 / 運営の固定 |
| **結果の取り込み** | Discord に貼られた凸の結果のスクショを運営が登録すること (✓ が付く) | 凸報告 / 代理凸 (メンバーに向けて) |
| **模擬の取り込み** | 同じく模擬のスクショを運営が登録すること | — |
| **締め凸** / **締め凸検索** | ボスを倒し切る凸 / その候補を運営が探すこと (声かけは Discord) | 締凸検索 / 締め凸候補検索 / 締め凸の依頼 |
| **運営** / **運営担当** / **👑 マスター** | 運営タブを使う人 / 任命された人 / ふるり | — |

## 画面に置かないもの (シンプルな画面・2026-10-23 ユーザー決定)

member_input=full (✏️ シーズン編集のスイッチ = 従来の画面) のときだけ出る。消さずに CSS や判定で隠している (`_homeSimple()` / `body.home-simple`)。

- ホームの「戦闘」カード (戦闘に入る・ボスの帯・本日の凸履歴・凸報告)・ボス状況カード・状態ボタン (オンライン / 模擬中 / 戦闘中)、運営タブ上の状態の数
- ヒーローの「🎯 あなたの3凸」、配信カードのタブ (わたしの凸 / 全体 / 時間割) — 自分の凸は 📅 きょうの凸、配信カードは 🧱 盤 + ✅ 確認しました
- 「この凸を引き受ける」(配信の割当を予約にする)、📣 お願い → 引き受ける (運営が 📌 を本人に聞く)
