# しりすこPAD 用語集 (画面の呼び方の正本)

2026-10-23 ユーザー決定「全体的に語句とか機能の呼び方を統一したほうが分かりやすい」。
画面・通知・ヘルプ・ツアー・練習モードの文言は **この表の「呼び方」** で書く。「使わない言い方」を画面に出さない
(コードのコメント・変数名・DB の列は変えなくてよい)。

| 呼び方 | 意味 | 使わない言い方 |
|---|---|---|
| **ユニオンレイド参加可能時間** (短く: **参加可能時間**) | レイドの日に出られる時間 (ブロック)。**メンバーは Discord で報告し、運営が登録する** (2026-10-24 決定 Q1。本人の画面では読むだけ・直すのも Discord) | 戦闘可能時間 / 出られる時間 / 凸可能時間 |
| **凸数** | 参加可能時間のブロックごとに何凸するか (合計 3 まで・入れなければおまかせ) | — |
| **ブロック** | 朝 5〜8 / 午前 9〜12 / 午後 13〜16 / 夕方 17〜20 / 夜 21〜翌0 / 深夜 翌1〜4 (レイドの日 5時〜翌4時を 4 時間ずつ・2026-10-24 から 6 つ) | — (1 時間の区切りは「時刻」) |
| **今期の確認** | シーズンごとの「この時間で参加します / 今回は難しい」 | — |
| **模擬** | 模擬戦のダメージと編成。Discord にスクショを貼る → 運営が登録 → ホームの「📘 登録された模擬」 | 模擬戦データ / 提出 (メンバーに向けて) |
| **PT / 編成①・②・③** | 属性ごとの編成 (1 属性に 3 つまで・2026-10-24 から)。「灼熱PT 編成②」 | — |
| **決定** (ボタンは **✅ ○○ を決定してメンバーに配信**) | 運営が組めたブロックまでをまとめてメンバーに出すこと (S4・2026-10-27)。見通しがついたら組んで**決定し直す** | — |
| **配信** | メンバーに出すこと (決定も配信の 1 つ。「配信されていません」= まだ決定が無い) | — |
| **📅 レイド予定表** | メンバーも見るタブ (S5・2026-10-27)。**盤** (ブロックのボタン → ボスの行の帯と名前の札・★ と太い枠が自分・2026-10-28) と **みんなの模擬** | 時間割 (メンバーに向けて) |
| **あなたの凸** (ホームの **📅 きょうの凸**) | 決定で決まった自分の凸 (ブロック・ボス・どの PT の どの編成)。全員ぶんは 📅 レイド予定表 | わたしの凸 / あなたの3凸 (シンプルな画面) |
| **✓ 凸の記録** | 運営が Discord の凸の報告 (結果のスクショ) を見て、決定の盤の名前の札を押して ✓ を付けること (札は「未完了」→「✓ 完了」・「✓ 完了」の札をもう一度押すと取り消し・S5・数字は入れない)。**メンバーは PAD で何も押さない**。状態の言い方は「✓ 完了」/「未完了」(2026-10-28) | ✓ 凸しました (メンバーに向けて) / 凸報告 / ✓ 済み / 塗りの札 |
| **予約** (S5 でシンプルな画面からは画面ごと隠した・従来の画面 member_input=full だけ「枠を予約する」と運営の「＋ 予約を登録」) | 「このブロックに この PT で凸したい」の希望。**シンプルな画面では Discord で運営に伝え、運営が 🧱 組む で 📌 を置いて残りを自動で組む** (2026-10-26 Q2「予約は廃止」) | 申請 / 約束 / 引き受けた凸 |
| **承認待ち** / **予約済み** (印は **🔒 予約**) | 予約の状態。**承認待ち** は PAD から予約を出せる設定 (従来の画面) の人だけ (出した → 運営が承認した)。シンプルな画面では S5 (2026-10-27) から新しい予約は作れない — 前から残っている予約は 🧱 組む の **🔒 凸の予約** に出るので、要らなければ運営が「取り下げる」。承認したら「予約が決まる」、組み直しに入れることは「予約を反映する」 | 申請中 / 固定中 / 予約で固定 / 予約を固定 |

| **結果の取り込み** | 凸の結果のスクショを数字ごと運営が登録すること (S5 で ⚔️ 戦況の下に畳んだ・ふだんは ✓ 凸の記録) | 凸報告 / 代理凸 (メンバーに向けて) |
| **模擬の取り込み** | 同じく模擬のスクショを運営が登録すること | — |
| **締め凸** / **締め凸検索** | ボスを倒し切る凸 / その候補を運営が探すこと (声かけは Discord) | 締凸検索 / 締め凸候補検索 / 締め凸の依頼 |
| **運営** / **運営担当** / **👑 マスター** | 運営タブを使う人 / 任命された人 / ふるり | — |

## 画面に置かないもの (シンプルな画面・2026-10-23 ユーザー決定)

member_input=full (✏️ シーズン編集のスイッチ = 従来の画面) のときだけ出る。消さずに CSS や判定で隠している (`_homeSimple()` / `body.home-simple`)。

- ホームの「戦闘」カード (戦闘に入る・ボスの帯・本日の凸履歴・凸報告)・ボス状況カード・状態ボタン (オンライン / 模擬中 / 戦闘中)、運営タブ上の状態の数
- ヒーローの「🎯 あなたの3凸」、配信カードのタブ (わたしの凸 / 全体 / 時間割) — 自分の凸は 📅 きょうの凸、配信カードは ✅ 確認しました (決定には盤が無い。従来のブロックの配信だけ 🧱 盤)・全員の凸は 📅 レイド予定表
- 「この凸を引き受ける」(配信の割当を予約にする)、📣 お願い → 引き受ける (運営が 📌 を本人に聞く)
- (S5・2026-10-27) 予約の画面 (メンバーの 🔒 予約カード・枠を予約する・模擬の 🔒 / 運営の 🔒 凸の予約 (前から残っている予約があるときだけ出す・新しい予約は作れない)・📸 のあとの「この編成で予約する」)・メンバーの「✓ 凸しました」
